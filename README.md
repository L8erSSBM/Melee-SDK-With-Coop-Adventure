# Melee-SDK-With-Coop-Adventure
Melee Source Development Kit coded in python aided by Melee Decomposition project, https://github.com/doldecomp/melee/.

**Core Gameplay / Characters:** 

Expanded Melee’s runtime so custom characters, two-human gameplay, independent stocks, friendly fire, C-Stick support, and persistent player state work beyond normal retail limitations.

**Stage Builder / Stage Select:**

Added custom-stage creation/import infrastructure plus a paged Stage Select system for extra stages, isolated Adventure content, and special mode launchers without replacing retail stages.

**Co-op Adventure / Slippi:** 

Built a full two-player Adventure Mode with shared progression, camera/event authority, character/state persistence, and Slippi Direct/rollback integration so both players can enter, play, quit, and return to their original online context.
